## 🇬🇧 English

A focused Android app that loads paginated product data from the [DummyJSON](https://dummyjson.com/products) API and renders it in Jetpack Compose with a complete, correctly-implemented **Paging 3** setup — proper `prevKey`/`nextKey` calculation, `getRefreshKey()`, `cachedIn(viewModelScope)`, and full handling of every `LoadState` (initial load, error + retry, empty, and append load/error + retry).

**Stack:** Kotlin · Jetpack Compose · Paging 3 · Ktor · Dagger Hilt · Coroutines/Flow

```bash
git clone https://github.com/<your-username>/paging3-products.git
```
